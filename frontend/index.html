A full-stack relational database portal built for educational demonstration. Demonstrates database normalization, foreign key constraints, citizen identity lifecycle, center allocation, and verified identity proof generation using Node.js, Express, and MySQL.

TABLE: Citizens

Citizen Demographic Registration

Record a new citizen's baseline identity into the centralized database.

Enter name as per official birth or school certificate
Must be today or in the past
10 digits without country code (+91)
TABLE: EnrollmentCenter

Enrollment Center Registration

Register an authorized center responsible for demographic verification and biometric capture.

TABLE: AadharApplication (Foreign Keys)

New Enrollment Application

Link an existing registered citizen with an enrollment center to generate an enrollment record.

Citizen must be registered first in Section 1
Relational Trigger Note: Submission links citizen_id and center_id via foreign key constraints. Application date is automatically defaulted to current date with initial status Pending.
